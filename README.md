# 🎮 Игра в угадывание

Простая консольная (или графическая) игра в угадывание на Python. 
Цель игры — угадать загаданное число (или слово) за ограниченное количество попыток.

## ✨ Особенности
- 🎵 Атмосферное звуковое сопровождение (файлы MP3).
- 🏆 Приятный звук победы (в стиле Final Fantasy).
- 💔 Звук проигрыша.
- Простой и понятный интерфейс.
